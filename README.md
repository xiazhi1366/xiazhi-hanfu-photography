## 🎵 音乐播放器

### 位置
Hero 区域右上角，圆形毛玻璃按钮。

### 交互方式
| 操作 | 功能 |
|------|------|
| **单击** | 播放 / 暂停切换 |
| **双击** | 打开文件选择器，导入本地音乐 |
| **hover** | 显示提示文字 |

### 图标状态
| 图标 | 状态 |
|------|------|
| 🎵 音符 + 脉冲光环 | 正在播放 |
| 🎵 音符 + 斜线 | 已静音 / 暂停 |

### 音乐模式
1. **生成模式**（默认）— Web Audio API 实时生成古风五声音阶
   - 笛子/箫（正弦波 + 高八度泛音）
   - 古琴拨弦（三角波衰减）
   - 持续低音 drone（C3 + G3 五度和声）
   - 旋律每次循环自动变奏

2. **上传模式** — 双击导入本地音频文件（mp3/wav/ogg 等）
   - 自动循环播放
   - 支持任意格式浏览器能播放的音频

### 自动播放说明
- 浏览器限制：音乐需要用户首次交互后才能播放
- 用户首次滚动/点击页面时自动启动
- **用户手动暂停后，不会再自动启动**

## 🔧 如何自定义

### 修改摄影师名字
搜索并替换以下内容：
- `夏至` → 你的名字（中文）
- `Xia Zhi` → 你的名字（拼音/英文）
- `xia_zhi_hanfu` → 微信号
- `xiazhi.hanfu@example.com` → 邮箱

### 修改价格
搜索 `¥199`、`¥288`、`¥388` 替换为你的价格。

价格卡片内容在 `<!-- Pricing -->` 注释下方，每个套餐对应一个 `.pricing-card` div。

### 修改作品
作品数据在 JS 的 `projects` 数组中，每条数据结构：

```javascript
{
  title: '作品名称',
  titleEn: 'English Title',
  group: '唐风雅韵',  // 分组：唐风雅韵 / 宋韵清雅 / 明制端庄 / 山水外景 / 影棚创作
  date: '2025.05',
  location: '洛阳',
  tags: ['齐胸襦裙', '黄金时刻'],
  image: '图片URL',
  desc: '作品描述文字...'
}
```

### 修改取景地
搜索 `<!-- Scenic Spots -->` 找到景区卡片区域，修改每个 `.spot-card` 的内容。

### 更换 Hero 轮播图
在 JS 中搜索 `heroImages` 数组，替换里面的图片 URL。

### 更换背景音乐
- **方法 1**：双击音乐按钮，选择本地音乐文件（临时，刷新后失效）
- **方法 2**：在 HTML 中找到 `<audio id="uploadedAudio">`，添加 `src="你的音乐地址"`，并在 JS 中将 `musicMode` 默认改为 `'uploaded'`

### 修改主题色
搜索 `:root` 中的 CSS 变量：
```css
--accent: #b8a88a;         /* 主色 */
--accent-bright: #c8baa0;  /* 亮色 */
--accent-soft: rgba(184,168,138,0.15); /* 柔光 */
```

## 🚀 部署方式

### 方式一：GitHub Pages（推荐，免费）
1. 在 GitHub 创建新仓库（public）
2. 上传 `hanfu-portfolio.html` 重命名为 `index.html`
3. 仓库设置 → Pages → Source 选 `main` 分支 → Save
4. 访问 `https://你的用户名.github.io/仓库名/`

### 方式二：Vercel / Netlify
- 拖拽 HTML 文件到 Vercel/Netlify 即可部署
- 支持自定义域名

### 方式三：本地预览
直接双击 `hanfu-portfolio.html` 在浏览器中打开即可。
